# Интерактивный квест-фестиваль «Игры Народов России»
### Полностью автономная система для площадок без интернета

Данный проект представляет собой полнофункциональное веб-приложение для проведения фестивалей традиционных народных игр на открытых площадках (стадионах, полянах, парках, этно-парках), где отсутствует подключение к сети Интернет.

---

## 📚 Документация для организаторов (Руководство в 3-х частях)

Для подготовки и проведения фестиваля подготовлена детальная документация:

1. 📦 [**ЧАСТЬ 1. Необходимое оборудование на площадке**](./README_PART_1_EQUIPMENT.md)
   - Требования к серверному ноутбуку (ОЗУ, процессор, автономность).
   - Выбор двухдиапазонного Wi-Fi роутера (Keenetic, MikroTik, TP-Link).
   - Кабели, электропитание в поле (аккумуляторы, инверторы, удлинители).
   - Размещение роутера на высоте и защита от солнца/осадков.
   - Физический инвентарь для ведущих станций.

2. ⚙️ [**ЧАСТЬ 2. Архитектура и функционал приложения**](./README_PART_2_OFFLINE_FEATURES.md)
   - Автономный архитектурный стек (React + Express + локальная JSON БД).
   - Особенности для участников: 22 игры, правила, интерактивная карта, сертификат мастера.
   - Защита от фальсификаций: последовательные 4-значные коды станций.
   - Возможности панели администратора: статистика, мониторинг, живой сброс площадки с выгрузкой в JSON/CSV.
   - Встроенный офлайн QR-ассистент и генератор стенда формата A4.

3. 🚀 [**ЧАСТЬ 3. Пошаговая инструкция по развертыванию**](./README_PART_3_DEPLOYMENT_GUIDE.md)
   - Шаг 1: Подготовка ноутбука до выезда (установка Node.js, `npm install`, `npm run build`).
   - Шаг 2: Настройка Wi-Fi роутера (SSID, открытая сеть, фиксация IP `192.168.1.100`, DHCP).
   - Шаг 3: Настройка брандмауэра (Windows Firewall / macOS / Linux) для порта `3000`.
   - Шаг 4: Запуск сервера `npm start` и печать плаката A4 на площадке.
   - Шаг 5: Решение нестандартных ситуаций (смартфоны без интернета, переподключение, резервное копирование).

## ⚡ Быстрый старт на ноутбуке организатора

```bash
# 1. Установка зависимостей (выполняется заранее при наличии интернета)
npm install

# 2. Сборка фронтенда
npm run build

# 3. Запуск сервера фестиваля
npm start
```

После запуска сервер доступен:
- На самом ноутбуке: `http://localhost:3000`
- Для смартфонов участников в локальной Wi-Fi сети: `http://192.168.1.100:3000`
