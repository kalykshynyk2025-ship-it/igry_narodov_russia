# ЧАСТЬ 3. Пошаговая инструкция по развертыванию на площадке без интернета

Данное руководство содержит исчерпывающие инструкции по подготовке оборудования дома/в офисе, настройке Wi-Fi роутера, конфигурированию сетевого экрана и запуску фестиваля в полевых условиях.

---

## ШАГ 1. Подготовка ноутбука до выезда на поляну (дома/в офисе с интернетом)

Все пакеты и зависимости должны быть установлены заранее, пока есть доступ к глобальной сети!

1. **Установите Node.js:**
   - Скачайте и установите **Node.js LTS** (версии 18, 20 или 22) с официального сайта: [nodejs.org](https://nodejs.org/).
   - Проверьте установку в терминале или командной строке:
     ```bash
     node -v
     npm -v
     ```
2. **Установите зависимости проекта:**
   - Перейдите в корневую папку приложения и выполните:
     ```bash
     npm install
     ```
3. **Выполните сборку фронтенда для продакшена:**
     ```bash
     npm run build
     ```
   - Команда создаст оптимизированные статические файлы в директории `dist/`.
4. **Проверьте локальный запуск:**
     ```bash
     npm start
     ```
   - Откройте в браузере `http://localhost:3000` и убедитесь, что приложение открывается, 22 игры отображаются, а вход в админку (`admin` / `kalyk2025`) работает.
5. **Настройте электропитание ноутбука:**
   - В параметрах электропитания Windows / macOS установите: **«При закрытии крышки — Действие не требуется (Не переходить в спящий режим)»**.
   - Отключите автоматический переход в спящий режим при бездействии.

## ШАГ 2. Настройка офлайн Wi-Fi роутера

1. Включите роутер в розетку (кабель интернета в WAN-порт подключать **не нужно**).
2. Подключите ноутбук к LAN-порту роутера кабелем Ethernet (или по Wi-Fi).
3. Войдите в веб-интерфейс роутера (обычно `192.168.1.1` или `192.168.0.1`, логин/пароль указаны на наклейке на дне роутера).
4. **Настройка имени сети (SSID):**
   - Установите понятное имя сети, например: `Igry-Narodov-Rossii` или `FESTIVAL-GAMES`.
   - **Рекомендация по безопасности:** Выберите **«Открытая сеть (Без пароля)»**.
     > *Почему без пароля?* На фестивале сотни участников разных возрастов. Ввод паролей от Wi-Fi вызывает очереди, опечатки и раздражение. Открытая сеть гарантирует подключение в 1 клик.
5. **Фиксация статического IP для ноутбука:**
   - В разделе *«DHCP-сервер / Статические адреса»* привяжите MAC-адрес ноутбука к постоянному IP, например: `192.168.1.100`.
   - Либо в настройках сетевого адаптера Windows вручную укажите:
     - IP-адрес: `192.168.1.100`
     - Маска подсети: `255.255.255.0`
     - Основной шлюз: `192.168.1.1`
6. **Настройка пула DHCP:**
   - Пул адресов: от `192.168.1.10` до `192.168.1.250`.
   - Время аренды IP (Lease time): 2–4 часа (чтобы освобождать адреса при смене потока гостей).

## ШАГ 3. Настройка брандмауэра (Сетевого экрана) на ноутбуке

Чтобы смартфоны участников могли подключаться к порту 3000 ноутбука, брандмауэр должен разрешать входящий трафик.

### Для Windows 10/11:
1. Нажмите `Win + R`, введите `control firewall.cpl` и нажмите Enter.
2. Слева выберите **«Дополнительные параметры»** (Windows Defender Firewall with Advanced Security).
3. В левой колонке нажмите **«Правила для входящих подключений» (Inbound Rules)** ➔ справа **«Создать правило...» (New Rule...)**.
4. Тип правила: **Для порта (Port)** ➔ Далее.
5. Протокол: **TCP**, Определенные локальные порты: **`3000`** ➔ Далее.
6. Действие: **Разрешить подключение (Allow the connection)** ➔ Далее.
7. Профиль: Отметьте **Частный (Private)** (и при необходимости Доменный/Общий) ➔ Далее.
8. Имя правила: `Festival Games Server (Port 3000)` ➔ Готово.

*Быстрый вариант через PowerShell (от имени Администратора):*
```powershell
New-NetFirewallRule -DisplayName "Festival Games Server (Port 3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

### Для macOS:
1. Перейдите в *Системные настройки ➔ Сеть ➔ Брандмауэр*.
2. Убедитесь, что `Node` или входящие подключения разрешены, либо временно отключите брандмауэр на время фестиваля в закрытой локальной сети.

### Для Linux:
```bash
sudo ufw allow 3000/tcp
```

## ШАГ 4. Развертывание и запуск на фестивальной поляне

1. **Физическая сборка штаба:**
   - Установите роутер на возвышении (1.5–2.5 м) в центре поляны (на крыше палатки, мачте или звуковом штативе).
   - Подключите роутер и ноутбук к источнику питания 220V (генератор/пауэрбанк/аккумулятор).
   - Соедините ноутбук и LAN-порт роутера кабелем Ethernet.
2. **Запуск сервера:**
   - Откройте терминал в папке проекта и запустите:
     ```bash
     npm start
     ```
   - Сервер запустится и будет слушать запросы по адресу `http://0.0.0.0:3000`.
3. **Проверка работы и генерация QR-кодов:**
   - Откройте на ноутбуке браузер: `http://192.168.1.100:3000`.
   - Войдите в панель администратора (кнопка «Админ-панель», пароль: `kalyk2025`).
   - Откройте вкладку **«Офлайн сеть и QR»** (или нажмите кнопку **«QR & Офлайн Wi-Fi»** в верхней панели).
   - Убедитесь, что IP-адрес определился как `192.168.1.100`.
   - Распечатайте плакаты A4 (кнопка «Распечатать плакат A4») или скопируйте QR-код для демонстрации на экране.
4. **Тестовое подключение со смартфона:**
   - Возьмите свой смартфон, подключитесь к Wi-Fi сети фестиваля (`Igry-Narodov-Rossii`).
   - Отсканируйте камерой QR-код со стенда или введите в браузере: `http://192.168.1.100:3000`.
   - Убедитесь, что страница загружается мгновенно, карточки игр листаются и регистрация работает.

## ШАГ 5. Памятка по решению частых полевых ситуаций (Troubleshooting)

### Ситуация 1: Смартфон пишет «Wi-Fi сеть без доступа в интернет»
- **Что происходит:** Android и iOS проверяют наличие глобального интернета (запросы к серверам Google / Apple). Поскольку интернета на поляне нет, система выдает уведомление.
- **Решение:** На экране смартфона появится всплывающее окно: *«В этой сети нет доступа к интернету. Оставаться подключенным?»*. Нужно нажать **«Да / Сохранять подключение»**. Мобильный браузер продолжит штатно работать с локальным IP `192.168.1.100:3000`.

### Ситуация 2: Страница не открывается с телефона («Не удается получить доступ к сайту»)
1. Проверьте, подключен ли телефон именно к Wi-Fi роутеру фестиваля.
2. Проверьте, не отключен ли Wi-Fi на смартфоне в пользу мобильной передачи данных (отключите пункт «Помощь Wi-Fi» / «Автопереключение на мобильные данные» в настройках телефона).
3. Проверьте, добавлен ли порт 3000 в исключения брандмауэра Windows на ноутбуке.
4. Проверьте IP-адрес ноутбука: в командной строке ноутбука введите `ipconfig` и сверьте адрес Ethernet/Wi-Fi адаптера.

### Ситуация 3: Защита данных и резервное копирование
- Вся база данных участников и прохождений сохраняется в реальном времени в файл `server/data/festival_database.json`.
- В любой момент во вкладке админки «Сводка» вы можете нажать **«Скачать базу участников (JSON)»** и **«Скачать базу участников (CSV)»** для мгновенного получения файлов отчета для организаторов и Минкульта / спорткомитета.
- Если ноутбук случайно перезагрузится, после повторного запуска `npm start` все данные участников, пройденные станции и выданные коды будут в полной сохранности.
