## 2. Ключевой функционал для участников

1. **Мгновенный старт без подтверждения по SMS и почте:**
   - Участник просто вводит своё имя (и при желании выбирает аватар).
   - Поддерживается вход под уже созданным профилем или выбор из списка активных участников на данном устройстве.
2. **22 традиционные игры народов России:**
   - Карточки игр с указанием этноса/региона (русские, буряты, татары, якуты, калмыки, башкиры, народы Кавказа, поморы, чукчи и др.).
   - Полные правила, количество участников, необходимый инвентарь и этнографическая справка.
3. **Интерактивная карта фестивальной поляны:**
   - Схематичное круговое или произвольное расположение станций.
   - Цветовая индикация: зеленый — станция пройдена, красный — ожидает прохождения.
   - Возможность загрузки реальной фотосхемы поляны/стадиона организатором.
4. **Защита от фальсификации (Система кодов станций):**
   - Участник не может сам отметить станцию пройденной — для зачёта требуется ввести уникальный 4-значный код, который знает только ведущий игры.
   - Коды выдаются последовательно, что исключает возможность угадывания.
5. **Именной Сертификат Мастера народных игр:**
   - При завершении всех или ключевых станций открывается красочный экран награждения с генерацией сертификата на имя участника.

## 3. Панель управления организатора (Админка)

- **Вход по паролю:** пароль по умолчанию `kalyk2025` (логин `admin`).
- **Управление игровыми станциями:**
  - Добавление, редактирование названий, правил, ведущих, сложности.
  - Автоматическая расстановка станций по кругу поляны в один клик.
- **Генератор последовательных кодов:**
  - Генерация списков проверочных 4-значных кодов для всех 22 станций.
  - Возможность распечатать коды в виде удобной шпаргалки для ведущих.
- **Мониторинг прохождений в реальном времени:**
  - Живой список всех зарегистрированных участников.
  - Детальная история прохождения каждого игрока с отметками времени.
  - Статистика самых популярных станций и средней активности.
- **Офлайн Wi-Fi & QR Ассистент:**
  - Автоматическое определение сетевых IP-адресов ноутбука (`192.168.1.100` и др.).
  - Мгновенная генерация QR-кода ссылки.
  - Готовый макет плаката формата A4 для печати на принтере прямо с поляны или перед выездом.
- **Инструмент сброса для новой площадки (`Reset Venue`):**
  - Защищен специальным мастер-паролем: `kalyk2025shynyk`.
  - Возможность в 1 клик выгрузить базу участников и протоколы прохождений в **JSON** и **CSV (Excel)**.
  - Чистый сброс прогресса и кодов при переезде на новую фестивальную поляну.
